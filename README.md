# Cariñitos by Jossy

Ecommerce de colgantes artesanales personalizables.

## Stack

- **Frontend:** React 18 + Vite + Tailwind + React Router v6 + Axios (`frontend/`)
- **Backend:** Node.js + Express + MySQL2 + JWT (`backend/`)
- **DB:** MySQL en Railway
- **Imágenes:** Cloudinary
- **Emails:** Gmail / Nodemailer

## Estructura

```
carinitos-app/
├── backend/   API REST (Express)
└── frontend/  SPA (React + Vite)
```

## Deploy

- Frontend: Vercel
- Backend: Railway
